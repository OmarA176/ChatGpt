# Expiry Radar (مدبّر الفائض)

Full-stack app for tracking household inventory expiry, reducing waste, and auto-building shopping lists.

## Stack
- React + Tailwind + Recharts + Lucide icons + Barcode scanner
- Node.js + Express + SQLite (better-sqlite3)

## Run
```bash
npm install
npm run dev
```
- Client: http://localhost:5173
- API: http://localhost:4000
